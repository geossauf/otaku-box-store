# أوتاكو بوكس — مشروع جاهز للرفع

راجع رسالة Claude للحصول على الخطوات الكاملة بالتفصيل. باختصار:

1. أنشئ مشروع Firebase مجاني + فعّل Firestore Database.
2. انسخ إعدادات Firebase (firebaseConfig) وألصقها في ملف `src/firebase.js`.
3. ارفع هذا المجلد كاملاً إلى GitHub.
4. اربط المستودع بـ Vercel (استضافة مجانية) ← Deploy.
5. رابط موقعك يصبح جاهزاً وشغالاً 24/7.
